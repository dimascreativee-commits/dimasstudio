DIMAS CREATIVE — HTML + CSS + JS

CARA MEMBUKA:
1. Extract ZIP ini.
2. Buka foldernya di Visual Studio Code.
3. Install extension "Live Server" jika belum ada.
4. Klik kanan index.html → Open with Live Server.

FILE:
- index.html  = struktur website
- style.css   = tampilan, layout, responsive, animasi visual
- script.js   = produk, modal detail, form order, WhatsApp
- assets/     = tempat foto/logo/portfolio

YANG PERLU DIGANTI:
1. assets/profile.jpg → foto kamu.
2. assets/portfolio-1.jpg sampai portfolio-4.jpg → karya kamu.
3. Buka script.js dan ganti:
   const WHATSAPP_NUMBER = "6281234567890";
   menjadi nomor WhatsApp kamu dengan format 628..., tanpa + dan tanpa 0 pertama.
4. Link Instagram/TikTok/Behance ada di bagian footer index.html.

CATATAN:
- Website ini HTML + CSS + JavaScript murni, tidak perlu React/Vite.
- Produk bisa diedit dari array "products" di script.js.
- Harga dan fitur produk juga bisa kamu ubah di sana.

FONT: Website sudah menggunakan Poppins sebagai font utama di seluruh halaman.

RESPONSIVE: Ukuran font/layout sudah disesuaikan untuk PC, tablet, dan HP. Desktop menggunakan clamp dan breakpoint 900px/600px.
